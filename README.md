# Sports Analytics Portfolio

Analytics professional with a background in applied data science and consulting, focused on transforming complex sport data into decisions — across high-performance, coaching, and sport-technology contexts.

This repository contains selected projects demonstrating applied modeling, visualization, and data-engineering workflows using real-world sport datasets.

---

## Projects

| Project | Description | Tools | Key Focus |
|---|---|---|---|
| [MLB: OPS + Stolen Bases](./mlb-ops-with-stolen-bases/) | Extends OPS to incorporate baserunning value and analyzes how player rankings shift | Python, Pandas | Metric design, exploratory analysis |
| [NFL Big Data Bowl: In-Stride Passing](./nfl-big-data-bowl/) | Quantifies how QB ball placement affects receiver acceleration and route disruption | R, tidyverse | Feature engineering, spatiotemporal analysis |
| [NFL Player Frame Visualization](./nfl-player-frame-viz/) | Visualizes player movement patterns across plays using frame-level tracking data | Python, Matplotlib | Tracking data visualization |

---

## Tech Stack

- **Languages**: Python, R
- **Libraries**: Pandas, Matplotlib, tidyverse, ggplot2
- **Platforms**: Google Colab, Kaggle
- **Data**: MLB season statistics, NFL Next Gen Stats tracking data
